# SHEERWOOD: размещение на Джино

Основной адрес: **https://sheerwood.moscow/**. Подготовлена статическая версия: сервер приложений, база данных и Node.js на хостинге не нужны. Текущий сайт GitHub Pages сохраняет свои адреса до запуска нового домена.

## Загрузка

1. В панели Джино добавьте домен `sheerwood.moscow` к хостингу и проверьте каталог сайта. Обычно это `domains/sheerwood.moscow`; в старых аккаунтах путь может отличаться. Используйте каталог, указанный в панели, а не произвольную папку `public_html`.
2. Если в каталоге уже есть сайт, сохраните его резервную копию перед заменой. Архив SHEERWOOD не содержит настроек почты и DNS.
3. Распакуйте `sheerwood-jino.zip` **непосредственно в корень сайта**. Файл `index.html`, скрытый файл `.htaccess`, папки `assets`, `images`, `videos` и разделы должны оказаться на одном уровне. Дополнительной папки `sheerwood-site` или `atrium-house` не нужно. Проверьте, что файловый менеджер переносит скрытый `.htaccess`.
4. Подключите DNS домена к хостингу по значениям из вашей панели Джино. Не заменяйте MX/TXT-записи почты: настройка сайта не должна нарушить `hello@sheerwood.moscow`.
5. После подключения DNS выпустите SSL-сертификат для `sheerwood.moscow` и `www.sheerwood.moscow` в панели Джино. Каноническая версия — HTTPS без www. Настройки перенаправления уже включены в `.htaccess` и учитывают прокси-заголовок Джино `X-Forwarded-Protocol`.
6. Откройте главную, контакты, глубокую страницу и видео. Убедитесь, что нет ошибки 500, сертификат действителен, фотографии и шрифты загрузились. Только после этого объявляйте переезд.

## Если открывается только главная, а оформление и разделы дают 403

Проверьте права распакованных каталогов. На Джино стандартные права: **755 для папок, 644 для файлов**. В раннем архиве не было отдельных записей каталогов; при строгой маске распаковщика это воспроизводимо создаёт каталоги с правами 700. Сборщик исправлен: новый архив содержит 78 явных каталогов с правами 755 и 650 файлов с правами 644. Проверено распаковкой при маске 077.

В файловом менеджере примените 755 ко всем каталогам **внутри сайта sheerwood.moscow**, включая `assets`, `images`, `videos` и папки разделов; к обычным файлам — 644. Не применяйте эти изменения ко всему аккаунту, другим доменам, почте или приватным ключам. Альтернатива — сохранить старую папку сайта как резервную копию и распаковать исправленный архив в новый пустой каталог, назначенный этому домену. При распаковке поверх существующих папок некоторые распаковщики оставляют прежние права 700: одной замены файлов может быть недостаточно. Это также проверено при локальной распаковке. Старую копию удалять не нужно.

После исправления запросы к `/assets/site.css`, `/images/sheerwood-logo.png` и `/kontakty/` должны возвращать 200. [Стандартные права Джино](https://o.jino.ru/help/faq/filemanagement/).

## Проверки после запуска

- `http://sheerwood.moscow/kontakty/` → `https://sheerwood.moscow/kontakty/` (301).
- `https://www.sheerwood.moscow/kontakty/` → адрес без www (301).
- `/kontakty/index.html` и `/kontakty` → `/kontakty/` (301).
- `/atrium-house/doma/` → `/doma/` (301); это совместимость пути **на новом домене**, не серверное перенаправление с github.io.
- `/craft/remont-kvartir.html` → `/remont-kvartir/` (301).
- Несуществующий адрес должен возвращать **HTTP 404**, а не главную с кодом 200.
- `/robots.txt` и `/sitemap.xml` доступны; карта содержит адреса только `https://sheerwood.moscow`.
- Телефон, почта, адрес и график соответствуют подтверждённым данным. Форма подготавливает письмо в почтовом приложении и не является серверной формой заявки.

## Поиск, регион и измерение результата

- Подтвердите домен в Яндекс Вебмастере и Google Search Console через их реальные проверочные записи/файлы. Отправьте `https://sheerwood.moscow/sitemap.xml`, затем проверьте несколько основных адресов инструментами инспекции URL.
- В Яндекс Вебмастере укажите фактический регион обслуживания. Для Яндекс Бизнеса создайте или подтвердите карточку с данными ниже. Регион и карточка проходят проверку самого сервиса; сайт не регистрирует их автоматически.
- Внесите реальные фотографии офиса/объектов и реальные отзывы, когда они будут доступны. Не обозначайте иллюстрации сайта как документальное портфолио выполненных заказов.
- Добавление Метрики или другого счётчика выполняется после получения настоящего идентификатора и решения владельца об обработке данных. Сейчас сторонние счётчики не установлены.
- После успешного запуска переключите canonical и социальные адреса старой GitHub Pages-версии на новый домен. GitHub Pages не поддерживает серверный `.htaccess`/301 для прежнего домена. Не отключайте старый сайт до проверки нового. Старый адрес Sites требует отдельного управления у своего провайдера.
- Через 2–4 недели оцените доступность, индексирование, запросы и переходы по данным кабинетов. Частотность и позиции в подготовленных файлах не выдуманы: они требуют данных поисковых сервисов.

## Что подготовлено

58 основных страниц: уникальные title/description, canonical, OG/X-превью, H1, навигационные цепочки, JSON-LD компании и страниц; Service на страницах услуг и VideoObject для 43 содержательных роликов. Карта сайта включает 58 адресов, 335 записей изображений и 43 видео. 11 старых адресов имеют серверные перенаправления. Локальные шрифты сохраняют прежнюю типографику. Настроены сжатие текстовых ресурсов, кеширование, кодировка UTF-8 и страница 404. Неиспользуемых ключевых тегов, фиктивных рейтингов, цен и географических страниц-дублей нет.

SEO/GEO опирается на доступные тексты, структуру разделов, подтверждённые данные компании и внутренние ссылки. Специальные AI-файлы или разметка не являются условием попадания в AI-поиск Google; гарантировать позиции, цитирование и сроки индексации нельзя. [Google: AI features](https://developers.google.com/search/docs/appearance/ai-features), [AI optimization](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).

Каталог и SSL сверены с [документацией Джино](https://o.jino.ru/spravka/hosting/) и [инструкцией по каталогу сайта](https://o.jino.ru/help/faq/filemanagement/upload-dir/). Региональная настройка — [Яндекс Вебмастер](https://yandex.ru/support/webmaster/ru/site-geography/site-region). ## Повторная сборка для разработчика

Исходники сайта — `sheerwood-site/`, сведения — `seo/business.json`, семантика и поисковые описания — `seo/pages.json`, таблица — `seo/semantic-map.csv`.

```sh
python3 scripts/prepare-search.py
python3 scripts/update-social-previews.py
python3 scripts/build-jino.py --output /absolute/new-release-folder --zip /absolute/sheerwood-jino.zip
```

Для генерации разметки нужны Python, Pillow и ffprobe. Каталог назначения должен отсутствовать. Пакет проверяется до создания ZIP: локальные ссылки/якоря, CSS-ресурсы, H1, уникальность метаданных, canonical и JSON-LD. Рядом с архивом создаётся SHA-256, рядом с каталогом — отчёт проверки.

GitHub Pages собирается отдельно, с префиксом `/atrium-house/`. **Не загружайте GitHub-сборку на Джино.** Сценарии сборки не выполняют загрузку, не меняют DNS, не покупают услуги и не подключают кабинеты аналитики.

## Справочник для ИИ: llms.txt

В исходники добавлен `sheerwood-site/llms.txt`. Он содержит подтверждённые сведения о компании, пояснения об использовании материалов и ссылки на страницы основного домена. Сборщик Джино автоматически копирует этот файл в корень полной сборки.

Для добавления в уже работающий сайт достаточно загрузить **только `llms.txt` рядом с `index.html` и `robots.txt`**. Небольшой архив `sheerwood-llms-jino.zip` содержит этот единственный файл без вложенных папок, с правами 644. Не требуется заменять `.htaccess`, страницы, фотографии или видео. После загрузки проверьте, что `https://sheerwood.moscow/llms.txt` возвращает текст файла и HTTP 200, а не HTML страницы ошибки.

Файл подготовлен локально; его загрузку владелец выполняет самостоятельно. Полные архивы, созданные ранее, этого дополнения ещё не содержат: для них нужен отдельный файл либо новая сборка.

Формат — [предложение llms.txt](https://llmstxt.org/), а не обязательный стандарт поисковых систем. Он не гарантирует обход, индексацию, цитирование или рекомендации нейросетей; Google прямо указывает, что этот файл не влияет на его поисковую видимость. Основные SEO-настройки и sitemap сохраняются. При изменении услуг, контактов или адресов страниц обновляйте справочник вместе с сайтом.
