# ATRIUM

Премиальный сайт компании по строительству домов под ключ, ремонту и прокладке коммуникаций.

Скролл — проход по дому: участок → порог → атриум → гостиная → кухня → спальня → спа → инженерия.

## Запуск

Откройте `index.html` в браузере.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
