# SHEERWOOD

Актуальная версия сайта строительной компании Sheerwood: 59 страниц, архитектура, проектирование, строительство домов, ремонт, инженерные системы и умный дом.

Работающий сайт: https://sheerwood.mboger777.chatgpt.site/

## Локальный просмотр

В этой папке выполните:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173/. Сборка и установка пакетов не требуются.

HTML-страницы расположены в папках направлений. Стили и сценарии — в `assets/`, фотографии — в `images/`, видео — в `videos/`. Пути ресурсов начинаются с `/`, поэтому сервер должен раздавать именно эту папку как корень сайта.

Контакты остаются демонстрационными. Форма заявки пока не отправляет данные.
