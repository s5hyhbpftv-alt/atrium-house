# SHEERWOOD

Актуальная версия сайта строительной компании Sheerwood: 69 страниц, архитектура, проектирование, строительство домов, ремонт, инженерные системы и умный дом.

Работающий сайт: https://s5hyhbpftv-alt.github.io/atrium-house/

## Локальный просмотр

В этой папке выполните:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173/. Сборка и установка пакетов не требуются.

HTML-страницы расположены в папках направлений. Стили и сценарии — в `assets/`, фотографии — в `images/`, видео — в `videos/`. Пути ресурсов начинаются с `/`, поэтому сервер должен раздавать именно эту папку как корень сайта.

Контакты остаются демонстрационными. Форма заявки пока не отправляет данные.

## GitHub Pages

Адрес: https://s5hyhbpftv-alt.github.io/atrium-house/

Публикация использует ветку `gh-pages`, корень `/`. Исходники в этой папке предназначены для корня домена. Чтобы подготовить их для адреса репозитория, из корня проекта выполните:

```sh
python3 scripts/build-github-pages.py --output dist/github-pages
```

Скрипт создаёт отдельный каталог, добавляет префикс `/atrium-house/` к ресурсам и навигации, проверяет внутренние ссылки и создаёт `.nojekyll`. Для обновления публикации содержимое результата переносится в ветку `gh-pages` с сохранением её истории.

## Умный дом: Aqara + Алиса

Раздел `/umnyi-dom/` включает обзор и десять подробных глав: архитектура системы, свет и шторы, климат, защита дома, сценарии жизни, вход и видеозвонок, розетки и энергия, бытовая техника, работа без интернета и этапы установки. В текстах приведены ссылки на документацию Aqara и Яндекса; совместимость описана для конкретных вариантов подключения.

Материалы раздела находятся в `images/aqara-alisa/` и `videos/aqara-alisa-*.mp4`. Семь сюжетов `sw-01`—`sw-07` подготовлены в 1920×1080, без звука, с загрузкой после нажатия. Главная заставка сохранена.

Дополнительная серия — 34 самостоятельные фотосцены в `images/smart-expansion/`, каждая используется один раз; пять служат обложками новых видео `videos/smart-home-shx-*.mp4`. Новые страницы имеют собственные композиции. Фильтр двенадцати сценариев, выбор поведения прибора и интерактивная схема локального/облачного управления работают без сервера и не управляют реальным оборудованием.

## Фотографии для направлений

30 самостоятельных фотосцен в `images/lifestyle/` распределены по 25 страницам архитектуры, домов, ремонта, интерьеров, инженерии, проектирования и ландшафта. Каждый новый кадр используется один раз. Для архитектуры и сада созданы отдельные фотокомпозиции; кадрирование проверяется на мобильных экранах.
